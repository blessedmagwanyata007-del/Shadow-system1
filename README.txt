SHADOW SYSTEM — PHONE INSTALL GUIDE

1. Upload this folder to a static website host that gives you HTTPS.
   Examples: GitHub Pages, Netlify, or Cloudflare Pages.
2. Open the resulting HTTPS website in Chrome on your Android phone.
3. Tap Chrome's ⋮ menu.
4. Choose "Add to Home screen" or "Install app".
5. Shadow System will appear as an app icon and open in standalone mode.

Important:
- The app stores your current progress locally on the device.
- The PWA works offline after its first successful load.
- Do not clear Chrome site data if you want to keep the local progress.
